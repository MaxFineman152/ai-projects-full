# Minesweeper AI

A knowledge-based AI agent that plays Minesweeper using logical inference.

---

## Overview
Implements a Minesweeper game environment and an AI that learns safe moves and mines using logical sentences about the board.

---

## Features
- Full Minesweeper game representation (grid, mines, scoring)
- Logical sentence-based knowledge system
- Infers safe cells and mines from constraints
- Expands knowledge using subset inference
- Random fallback move selection

---

## Technologies
- Python  
- Sets and logic-based reasoning  
- Object-oriented design  

---

## Outcome
An AI that progressively learns safe moves and identifies mines without guessing whenever possible.
