# Sentence Parser (NLP Grammar + Noun Phrase Extraction)

A natural language processing tool that parses sentences using a context-free grammar and extracts noun phrase chunks.

---

## Overview
Uses a predefined CFG grammar with NLTK to parse sentences into syntax trees and identify noun phrases.

---

## Features
- Context-free grammar for English sentence structure  
- Chart parsing using NLTK  
- Sentence preprocessing (tokenization + cleanup)  
- Syntax tree visualization  
- Extracts noun phrase chunks (NPs without nested NPs)  

---

## Technologies
- Python  
- NLTK (Natural Language Toolkit)  
- Context-Free Grammar (CFG)  
- Regular expressions  

---

## Input
- A sentence typed by the user or loaded from a file  

---

## Output
- Parse tree of the sentence  
- List of noun phrase chunks
