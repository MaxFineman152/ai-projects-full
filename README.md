# PageRank

An implementation of the PageRank algorithm using both sampling and iterative methods.

---

## Overview
Computes PageRank scores for a corpus of HTML pages based on their link structure.

---

## Features
- Builds a link graph from HTML files  
- Handles pages with no outgoing links  
- Implements PageRank using:
  - Sampling method (random walks)  
  - Iterative convergence method  
- Uses damping factor for random jumps  
- Stops iteration when values converge  

---

## Technologies
- Python  
- Regular expressions  
- Random sampling  
- Graph-based computation  

---

## Output
PageRank values for each page computed using both sampling and iterative approaches.
