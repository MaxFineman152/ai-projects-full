# Tic Tac Toe AI (Minimax with Alpha-Beta Pruning)

A playable Tic Tac Toe game with an optimal AI opponent using the minimax algorithm.

---

## Overview
Implements Tic Tac Toe with a game engine and an AI that uses minimax search with alpha-beta pruning to play perfectly.

---

## Features
- Full Tic Tac Toe game logic  
- Minimax algorithm AI  
- Alpha-beta pruning for efficiency  
- Game state evaluation (win/draw detection)  
- Interactive Pygame UI  
- Play as X or O against the computer  

---

## Technologies
- Python  
- Pygame  
- Minimax algorithm  
- Alpha-beta pruning  

---

## Gameplay
- Human vs AI mode  
- Click-based graphical interface  
- Automatic AI move calculation  
- Detects win, loss, or tie states  

---

## Output
- Visual Tic Tac Toe board  
- Real-time gameplay in Pygame window  
- Optimal AI moves every turn
