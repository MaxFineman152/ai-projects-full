# Nim AI (Q-Learning)

A reinforcement learning AI that learns to play Nim by training through self-play.

---

## Overview
Implements the game of Nim and trains an AI using Q-learning to choose better moves over time.

---

## Features
- Nim game engine with multiple piles  
- Q-learning AI agent  
- Epsilon-greedy exploration  
- Self-play training loop  
- Human vs AI mode  

---

## Technologies
- Python  
- Reinforcement learning (Q-learning)  
- Random action selection  

---

## Output
- Trained AI after self-play  
- Human vs AI gameplay  
- Winner announcement
